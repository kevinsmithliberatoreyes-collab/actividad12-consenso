# Prototipo de Consenso Distribuido (Raft)

Este repositorio contiene la simulación del algoritmo de consenso Raft para la Actividad 12 de Sistemas Distribuidos.

## Instrucciones de ejecución
1. Asegúrate de tener Python 3 instalado.
2. Descarga el archivo `raft_consenso.py` directamente desde este repositorio.
3. Abre una terminal en la misma carpeta donde descargaste el archivo.
4. Ejecuta el archivo con el siguiente comando:
   ```bash
   python raft_consenso.py
